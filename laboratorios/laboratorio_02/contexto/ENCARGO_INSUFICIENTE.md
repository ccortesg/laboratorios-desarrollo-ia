# Encargo con contexto insuficiente

**Ejemplo didáctico preparado para el libro.** Este encargo representa el punto de partida del ejercicio; no es una conversación histórica ni una orden para modificar el laboratorio.

> El catálogo ya funciona. Organiza la arquitectura y deja preparado lo necesario para continuar con la aplicación. Conserva lo importante de lo que veníamos haciendo y aplica las mejoras que consideres convenientes.

Antes de actuar, anota qué información falta para decidir el alcance, localizar la implementación, reconocer las reglas que deben conservarse y evaluar una entrega. Compara después tus preguntas con el paquete de contexto, sin utilizar el historial de una conversación.
