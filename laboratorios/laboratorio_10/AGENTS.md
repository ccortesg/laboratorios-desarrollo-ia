# Instrucciones del laboratorio 10

Lee README y contexto/CONTRATO_AUTOMATIZACION.md. El contrato se registró antes de implementar; su copia exacta forma parte de la preparación editorial. Trabaja sólo con datos sintéticos y copias locales.

Los tres estados conservan la solución 9. Base no contiene operar.py; propuesta continúa tras un rechazo de importación; solución exige importación confirmada. Todos los 74 casos heredados deben aprobar en los tres estados. Los ocho T de base quedan NO EJECUTADO; el único fallo didáctico admitido en propuesta es T02/AssertionError. La solución debe aprobar 82 casos con navegador real.

El operador usa una instantánea entrada.csv dentro de una carpeta nueva, dos CLI fijas y un recibo. No recibe comandos ni planes ejecutables. Conserva el archivo SQLite elegido y la protección de componentes del laboratorio. No elimina recibos ni reinicializa bases.

Conserva los 71 archivos heredados declarados en PROCEDENCIA.json, las huellas capturadas y finales y las evidencias de desarrollo. Las regresiones RO01 y de recursos SQLite son infraestructura y no se suman a T01–T08. El registro de una operación BLOQUEADA sin proceso no debe adquirir capturas ni huellas ficticias.

Una importación confirmada no se revierte si falla la consulta. No observar confirmación tras una interrupción tampoco demuestra ausencia de cambios. El límite debe quedar explícito; no añadir reintentos ni recuperación destructiva.

Sin navegador, el alcance completo queda NO EJECUTADO. No atribuyas una ejecución local a Windows ni a una herramienta comercial. No publiques, no alteres históricos y no implementes el reto del lector.
