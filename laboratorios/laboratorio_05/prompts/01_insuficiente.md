# Encargo insuficiente

**Ejemplo didáctico preparado para el libro. No enviado a Copilot.**

> Haz un resumen del inventario y deja todo listo.

Faltan la diferencia entre artículos y unidades, el almacén, el filtro de nombre,
la forma de salida, los archivos implicados, las reglas que deben conservarse y
los criterios de aceptación. Tampoco precisa si se espera una función, una terminal
o una aplicación completa. No permite reconocer cuándo el trabajo está terminado.
