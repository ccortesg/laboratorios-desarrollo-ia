# Ejemplo didáctico preparado para el libro

Revisa el cambio como un contrato de intercambio. Comprueba con datos sintéticos:
cantidad absoluta, cero, par omitido, duplicado, código desconocido y error tardío.
Ejecuta dos importaciones sobre la misma conexión y consulta esa conexión con la
función real del catálogo. Explica cualquier diferencia entre filas leídas,
validadas y aplicadas. Revisa la diferencia propuesta→solución y registra qué
caso detecta el defecto. No declares verificada la web sin navegador real.

No se incluye una respuesta simulada ni una transcripción de uso comercial.
