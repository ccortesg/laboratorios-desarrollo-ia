# Instrucciones del laboratorio 7

Lee README.md y el paquete contexto antes de cambiar código. Este material es
sintético y local. Conserva estados, datos de referencia, diferencias y evidencia
histórica; trabaja en una copia propia y registra una ejecución nueva.

El contrato vigente es contexto/CONTRATO_INTEGRACION.md. C/B/N/P/W conservan su
significado. El nuevo incremento importa existencias absolutas por CSV y consulta
la conexión modificada. No cambies códigos exactos por búsquedas normalizadas.
No añadas pantalla de importación, API externa, reservas ni aplicación completa.

Propuesta contiene un defecto intencional de suma: I01 e I07 deben FALLAR. Base
no tiene importador: 17 casos I NO EJECUTADO. Solución debe aprobar 51 casos con
navegador real. Las pruebas usan sus datos iniciales aislados; no cambies esas
expectativas para acomodar una importación.

El recolector de soporte conserva la corrección de huellas. Verifica captura,
sanea y compara bytes finales. No repares registros históricos ni atribuyas una
ejecución local a herramientas comerciales. Usa los estados APROBADO, FALLIDO,
BLOQUEADO y NO EJECUTADO para comprobaciones.

Los prompts son ejemplos didácticos. Los capítulos siguen pendientes de revisión
editorial del autor. No accedas a sistemas reales ni publiques fuera del entorno.
