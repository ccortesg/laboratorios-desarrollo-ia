# Encargo insuficiente: ejemplo didáctico

El siguiente texto se preparó para el libro. No es una interacción ejecutada con
Grok Build ni una conversación histórica:

> Haz una aplicación bonita para consultar el inventario. Que tenga un buscador y
> muestre cuántos artículos hay en cada almacén.

No precisa qué significa «hay», si se cuentan artículos o existencias, cómo se
tratan los artículos deshabilitados, qué función reutilizar ni cómo comprobar la
selección. También permite interpretar que hay que construir una aplicación
completa. El diseño visual queda mezclado con reglas que ya están resueltas.

Mejora el encargo con el contexto de `contexto/CONTEXTO.md` y los criterios de
`ALCANCE.md`. Los ejemplos siguientes separan planificar, implementar y revisar.
