# Revisar: prompt didáctico preparado para el libro

No es una respuesta simulada ni una interacción comercial: es un recurso
reutilizable para pedir una revisión independiente del cambio.

```text
Revisa la aplicación de mi_practica/ contra ALCANCE.md. Separa lo que ves
en el código de lo que observas al ejecutar. No añadas funcionalidades.

Comprueba que la regla por almacén y los 26 criterios heredados no cambian.
Revisa las diferencias frente a estados/base, especialmente servidor.py
y web/app.js. Confirma dónde se lee el almacén seleccionado y dónde se
aplica la disponibilidad. Busca valores fijos que puedan falsear el resumen.

Ejecuta las comprobaciones de dominio, terminal y HTTP de esta copia.
En un navegador real, consulta ALFA, cambia a BETA y vuelve a consultar.
Prueba una búsqueda sin coincidencias y un fallo controlado de transporte.
Registra entradas, salidas, estado visible y código de salida de cada batería.

No presentes una consulta HTTP como prueba de que el formulario funciona.
No marques APROBADO el extremo a extremo si W05–W06 no se ejecutaron.
Conserva fallos intencionales y evidencia histórica en sus carpetas originales.

Entrega un cierre con APROBADO, FALLIDO, BLOQUEADO o NO EJECUTADO, los
problemas concretos pendientes y el siguiente paso verificable. Distingue
ejecución local, ejemplos didácticos y uso comercial efectivamente acreditado.
```
